## ✅ 修复1: Streak 跨靴牌统计问题（高优先级）

### 问题描述
Streak 分析器使用跨靴牌的连接数据（combined_data）来计算连续次数，导致：
- 统计信息显示：庄连3次
- Streak模型说：庄连6次（包含历史靴牌最后的3次）
- 违反百家乐本质（每靴独立）

### 根本原因
```python
# analyzer.py (修复前)
def predict_by_streak(self):
    streak_type, streak_count = get_current_streak(self.data_no_tie)
    # self.data_no_tie = 历史 + 当前（跨靴牌）
```

### 修复方案
```python
# analyzer.py (修复后)
class BaccaratAnalyzer:
    def __init__(self, data, current_shoe_data=None):
        self.data = data
        self.current_shoe_data = current_shoe_data if current_shoe_data is not None else data
        self.current_shoe_no_tie = [x for x in self.current_shoe_data if x != 'T']

def predict_by_streak(self):
    # 只使用当前靴牌数据
    streak_type, streak_count = get_current_streak(self.current_shoe_no_tie)
```

### 影响
- ✅ Streak 现在只分析当前靴牌的连续
- ✅ 符合百家乐本质（靴间独立）
- ✅ 预测更准确

### 修改文件
- `analyzer.py`: 添加 `current_shoe_data` 参数，修改 `predict_by_streak`
- `ensemble.py`: 传入 `current_shoe_data` 到 `BaccaratAnalyzer`

## ✅ 修复2: 平票处理错误（高优先级）

### 问题描述
当模型投票结果为平票时（如 B:5, P:5）：
- 显示："多数支持庄"（错误！应该是平票）
- 推荐逻辑混乱

### 根本原因
```python
# ensemble.py (修复前)
vote_winner = max(votes.items(), key=lambda x: x[1])[0]
# 平票时，max() 返回第一个（'B'总在前面）
```

### 修复方案
```python
# ensemble.py (修复后)
# 找出投票最多的（处理平票情况）
max_vote_count = max(votes.values())
winners = [k for k, v in votes.items() if v == max_vote_count]

if len(winners) > 1:
    # 平票：选择概率最高的
    vote_winner = max(winners, key=lambda x: {'B': final_b, 'P': final_p, 'T': final_t}[x])
    is_tie_vote = True
else:
    vote_winner = winners[0]
    is_tie_vote = False
```

### 影响
- ✅ 平票时选择概率高的
- ✅ 明确标注平票状态
- ✅ decision_note 会说明"模型投票平局"

### 修改文件
- `ensemble.py`: 修改投票逻辑，添加 `is_tie_vote` 标志
- `visualizer.py`: 显示平票标注（"庄/闲平票"）

## ✅ 修复4: 固定 LSTM 随机种子（中优先级）

### 问题描述
LSTM 每次预测可能略有不同，导致：
- 快速预测：推荐庄
- 详细预测：推荐闲（创建新实例）
- 用户困惑

### 根本原因
```python
# TensorFlow/Keras 的内部随机性
# 每次创建模型或预测时，可能有微小差异
```

### 修复方案
```python
# predictor.py (修复后)
def train(self, sequence_length=20):
    import tensorflow as tf
    
    # 固定随机种子，确保训练一致性
    np.random.seed(42)
    tf.random.set_seed(42)
    # ...

def predict(self, recent_data):
    import tensorflow as tf
    
    # 固定随机种子，确保预测一致性
    np.random.seed(42)
    tf.random.set_seed(42)
    # ...
```

### 影响
- ✅ LSTM 预测更一致
- ✅ 快速预测 = 详细预测
- ✅ 减少随机性

### 注意
- ⚠️ 这会牺牲一些随机探索能力
- ⚠️ 但提高了用户体验的一致性

### 修改文件
- `predictor.py`: 在 LSTM 的 `train` 和 `predict` 方法中添加随机种子设置
