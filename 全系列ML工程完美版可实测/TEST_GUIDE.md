# 阶段1功能测试指南

## 🎯 测试目标

验证自适应权重系统是否正常工作，能否解决"连续预测同一结果"的问题。

---

## 📋 测试场景

### **场景1：测试连续预测错误的自动调整**

#### **步骤：**

1. 启动程序
```bash
python main.py
```

2. 选择"1. 实时记录模式"

3. 输入以下序列（模拟闲连续出现）：
```
B → B → P → P → P → P → P → P → P
```

#### **预期结果：**

- 前几次预测可能会出错
- **关键观察点：** 连续预测错2-3次后，应该看到：
  ```
  🔧 连续预测错误X次，调整权重
  ```
- 调整后，预测应该改变方向
- 不再连续预测同一个结果

---

### **场景2：观察权重调整效果**

#### **步骤：**

1. 导入测试数据（闲长龙）：
```
选择"2. 批量导入数据"
输入：PPPPPPPPPP  （10个闲）
```

2. 进入实时记录模式
3. 继续输入：P → P → P

#### **预期结果：**

- 初始可能预测庄（斩龙策略）
- 连续错误后，系统调整
- 后续开始预测闲（跟龙）

---

### **场景3：查看详细预测信息**

#### **步骤：**

1. 记录至少10局数据
2. 按 `.` 查看详细分析
3. 观察预测结果中的信息

#### **预期显示：**

```
🎯 预测结果
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
推荐投注: 闲 (推荐)
置信度: 68.5%
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

概率分布:
  庄: 庄 40.4%
  闲: 闲 55.3%
  和: 和 4.3%

分析: Trend: 闲家趋势强势

使用模型数: 6
模型一致性: 71.4%
模型投票: 庄 2 | 闲 4 | 和 0
```

如果之前有连续错误，还会显示：
```
🔧 连续预测错误3次，调整权重
```

---

## 🔍 验证要点

### ✅ **必须通过的测试：**

1. **自动调整触发**
   - [ ] 连续错2次后显示"微调权重"
   - [ ] 连续错3次后显示"调整权重"

2. **预测改变**
   - [ ] 调整后，推荐结果发生变化
   - [ ] 不再一直预测同一个

3. **正常运行**
   - [ ] 没有程序崩溃
   - [ ] 预测功能正常
   - [ ] 数据保存正常

### 📊 **观察指标：**

1. **调整频率**
   - 正常：每10-15局调整1-2次
   - 异常：每次都调整 或 从不调整

2. **准确率变化**
   - 在长龙场景下，准确率应该提升
   - 不应该出现连续5次以上预测错误

## 🐛 问题排查

### **如果看不到权重调整提示：**

1. 检查是否连续预测错误
2. 确认是否输入了至少5局数据
3. 查看是否有报错信息

### **如果程序出错：**

1. 检查错误信息
2. 确认所有依赖已安装
3. 查看是否有文件权限问题

### **如果预测还是一直相同：**

1. 检查是否真的连续错误
2. 查看是否在实时记录模式（批量导入不会实时调整）
3. 确认 `prediction_history.py` 文件存在
