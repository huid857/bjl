## 🐛 常见问题排查

### 问题1: 看不到 DataDriven 模型
**可能原因：**
1. 历史数据不足（<50局）
2. 当前模式在历史中没有足够样本
3. 代码报错（但被捕获）

**排查步骤：**
```python
# 在 data_driven_predictor.py 的 predict() 方法中添加打印
print(f"DEBUG: can_predict = {self.can_predict()}")
print(f"DEBUG: shoes count = {len(self.shoes)}")
print(f"DEBUG: total rounds = {self.analyzer.total_rounds}")
```

### 问题2: 系统启动报错
**可能错误信息：**
```
ModuleNotFoundError: No module named 'historical_analyzer'
```

**解决方案：**
```bash
# 确认文件在正确位置
ls -l historical_analyzer.py
ls -l data_driven_predictor.py

# 如果是路径问题，确保在项目根目录运行
cd D:\Backup\Music\bjl
python main.py
```

### 问题3: 预测很慢
**可能原因：**
- 每次预测都重新分析历史数据
- LSTM模型拖慢（已知问题）

**排查：**
```
观察"正在分析..."的时间
- <1秒：正常
- 1-3秒：可接受
- >5秒：有问题（可能是LSTM）
```

**临时解决：**
```
禁用LSTM：
在 predictor.py 的 LSTMPredictor.can_train() 中：
return False  # 临时禁用
```
