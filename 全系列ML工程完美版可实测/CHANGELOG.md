# 更新日志

## v1.1.0 - 自适应权重系统 (2025-10-29)

### 🎉 重大更新

#### **核心功能：自适应权重调整系统**

系统现在具备**自我学习和纠错能力**！

### ✨ 新增功能

1. **预测历史记录**
   - 系统会记录每次预测的结果
   - 追踪各模型的准确率
   - 最多保留50次历史记录

2. **动态权重调整**
   - 当连续预测错误≥2次时，自动调整模型权重
   - 表现差的模型权重降低（最多减半）
   - 表现好的模型权重提升
   - 实时适应当前牌局特征

3. **智能纠错机制**
   - 连续错3次 → 大幅调整权重
   - 连续错2次 → 轻微调整权重
   - 单个模型连续错误 → 针对性降权

4. **可视化反馈**
   - 显示权重调整信息
   - 提示调整原因
   - 让用户了解系统学习过程

### 🔧 技术改进

#### **新增模块**
- `prediction_history.py` - 预测历史记录管理

#### **更新模块**
- `ensemble.py`
  - 添加 `PredictionHistory` 集成
  - 新增 `update_prediction_result()` 方法
  - 新增 `_get_weight_adjustment()` 方法
  - 新增 `_adjust_model_weight()` 方法
  - 所有预测自动记录基础权重和调整后权重

- `main.py`
  - 集成预测历史追踪
  - 每次输入结果后自动更新预测历史
  - 持久化 `PredictionHistory` 实例

### ⚠️ 注意事项

1. **预测历史在内存中**
   - 每次启动程序会重置
   - 不影响历史数据库
   - 只用于当前会话的实时调整

2. **权重调整说明**
   - 自动进行，无需手动操作
   - 会在预测时显示调整信息
   - 不会修改模型本身，只调整权重

3. **适用范围**
   - 所有预测模式都会使用
   - 实时记录模式效果最明显
   - 批量导入也支持
