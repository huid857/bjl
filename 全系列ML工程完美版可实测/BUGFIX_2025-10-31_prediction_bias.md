# 预测偏向庄的问题修复报告

## 日期
2025-10-31 23:45

## 问题描述
用户反馈系统持续偏向预测"庄"，即使当前靴牌数据显示"闲"的比例明显更高（庄42.4% vs 闲51.5%），系统仍然一直预测庄，导致连续预测错误多次。

## 根本原因分析

### 1. 历史数据偏向
历史1308局数据中：
- **庄：52.64%**（非和局中）
- **闲：47.36%**

这比理论概率（庄50.7% vs 闲49.3%）偏差更大，导致所有基于历史数据训练的ML模型（LSTM, RandomForest等）系统性地倾向预测庄。

### 2. Frequency预测器使用错误数据
原代码：
```python
freq_pred = self.freq.predict(self.combined_data)  # 使用历史+当前数据
```

`combined_data`包含大量偏向庄的历史数据（1308局），淹没了当前靴牌（33局）的真实趋势。

### 3. 决策逻辑过度依赖模型投票
原逻辑：当概率差异<15%时，优先选择模型投票结果而非概率。
- 概率显示：闲50.x% > 庄47.x%
- 但6个模型投票给庄 vs 2个投票给闲
- 最终选择庄（错误）

### 4. 权重计算问题
原代码：`adjusted_weight = weight * (confidence / 100)`
- Frequency权重3.0，但置信度仅26.4%（样本少），实际权重仅0.79
- RandomForest权重0.5，但置信度77.4%，实际权重0.39，仍有较大影响

### 5. 极端概率扭曲结果
RandomForest预测：庄95.2% vs 闲4.8%（极端偏向）
虽然权重低，但极端概率严重拉高了庄的加权平均值。

## 修复方案

### 1. 调整模型基础权重 ✅
**增加当前靴牌模型权重**：
- Trend: 1.5 → **3.0** (当前趋势最可靠)
- Frequency: 1.2 → **3.0** (直接反映当前实际)

**降低历史/ML模型权重**：
- Historical: 1.0 → **0.7** (历史可能不反映当前)
- Streak: 0.8 → **0.6** (断龙策略常失效)
- LSTM: 1.2 → **0.8** (容易过拟合历史)
- RandomForest: 1.2 → **0.5** (经常极端偏向)
- LSTM_V2: 1.3 → **0.9**
- RF_V2: 1.3 → **0.6**

### 2. 修复Frequency使用数据 ✅
```python
# 修复前
freq_pred = self.freq.predict(self.combined_data)

# 修复后
freq_pred = self.freq.predict(self.current_shoe_data, window=len(self.current_shoe_data))
```
只分析当前靴牌频率，避免被历史数据偏向影响。

### 3. 优化权重-置信度关系 ✅
```python
# 对于当前靴牌模型（Frequency, Trend），降低置信度影响
if model_name in ['Frequency', 'Trend']:
    confidence_factor = 0.7 + 0.3 * (confidence / 100)  # 最低70%
else:
    confidence_factor = confidence / 100  # 历史/ML模型
```
当前靴牌模型基于实际数据，即使样本少也更可靠。

### 4. 限制极端概率 ✅
```python
max_prob = 75.0  # 最大不超过75%
min_prob = 15.0  # 最小不低于15%
```
避免单个模型的极端预测（如RandomForest的95.2%）扭曲整体结果。

### 5. 优化决策逻辑 ✅
```python
# 修复后：几乎完全基于概率，投票仅作参考
if prob_winner != vote_winner:
    if prob_diff >= 1.0:  # 降低阈值：1%差异就优先用概率
        recommendation = prob_winner
    elif consistency < 80:  # 提高要求：除非模型高度一致(>80%)
        recommendation = prob_winner
    else:
        recommendation = vote_winner  # 仅在概率<1%且一致性>80%时
```

### 6. 加强权重自适应调整 ✅
- 连续错误2次：调整系数 0.5/2.0
- 连续错误3次：调整系数 0.25-0.4/2.5
- 连续错误4次：调整系数 0.2-0.4/3.0
- 连续错误5次+：调整系数 0.05-0.4/4.0

## 修复效果

### 测试场景
- 数据：`TPPPBPBBBPBPTPBBPBPBBBPPPPPBPPPBB` (33局)
- 实际：庄14局(42.4%) 闲17局(51.5%)

### 修复前
- 推荐：**庄**
- 概率：庄56.6% 闲41.2%
- 投票：庄6票 闲2票
- ❌ 与实际相反

### 修复后
- 推荐：**闲** ✅
- 概率：闲48.5% 庄47.4%
- 投票：庄6票 闲2票（但优先使用概率）
- 实际权重：闲4.978 vs 庄2.221（闲是庄的2.24倍）
- ✅ 符合当前靴牌趋势
